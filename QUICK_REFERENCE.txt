# QUICK REFERENCE - Building .dmg for The Moon And Stars

## One-Line Summary
Complete C++ Qt 6 project ready to build macOS .dmg installer on a Mac.

---

## QUICK START (on macOS)

```bash
# 1. Install prerequisites (one-time)
xcode-select --install
brew install cmake

# 2. Navigate to project
cd /path/to/themoonandstars

# 3. Build (single command)
chmod +x build_mac.sh
./build_mac.sh

# 4. Get your DMG
# Check: release/TheMoonAndStars.dmg
```

**Time:** 15-30 min (first build), 5 min (subsequent)

## TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| cmake not found | `brew install cmake` |
| Xcode license error | `sudo xcode-select --install` |
| Python not found | `brew install python3` |
| Network timeout | Check internet, retry build |
| Build fails | Read error message, see BUILD_MACOS.md |
